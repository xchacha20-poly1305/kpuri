Url

class Url

An immutable URI reference (RFC 3986).

Components are stored in encoded form. Decoded getters expose their text, while toString preserves valid percent escapes and uses a lowercase scheme. A null component is absent. An empty string is present but empty (RFC 3986 §5.3).

pathSegments
Link copied to clipboard
val pathSegments: List<String>

Segments of encodedPath: split on / first, then percent-decode each piece. An empty path has no segments, and a leading / is not itself a segment, so "" is [], "/" is [""], and "/a/b" is ["a", "b"]. %2F stays inside one segment; path decodes it to / and loses that boundary.
